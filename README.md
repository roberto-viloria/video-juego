# Guardians of the Ancient Kingdom – Juego en Python

Este proyecto contiene un **juego de batalla de personajes en Python** usando Programación Orientada a Objetos (POO).  
Los personajes se enfrentan por turnos hasta que uno de ellos queda sin vida.

 

## Archivos

- `juego.py` – Código principal del juego con clases, subclases y lógica de batalla.

## Cómo ejecutar

1. Asegúrate de tener Python instalado.  
2. Ejecuta el juego con:

```bash
python juego.py
```
